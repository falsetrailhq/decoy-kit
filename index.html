decoy-kit

Inert decoy files for the places intruders and AI agents look first: .env, kubeconfig, MCP config, git and npm credentials, SSH config and shell history. Each one points at a domain you control, with its own id, so the first request tells you which file was found. Everything runs in your browser; nothing is sent anywhere.

Before you plant anything

Point wildcard DNS (*.decoy.example.com) at a server whose logs you watch, for example listener.mjs from the repo. Keep the manifest off the systems you plant on. Only use decoys on systems you own or are authorised to test. The secrets are random strings with no real provider prefix, so they won't trip secret scanners or provider revocation.
